This repository contains a comprehensive analysis of laptop data, focusing on data cleaning and exploratory data analysis to understand laptop pricing factors and specifications relationships.

Dataset source: [Kaggle Laptop Data](https://www.kaggle.com/datasets/ehtishamsadiq/uncleaned-laptop-price-dataset?resource=download&select=laptopData.csv)

This project consists of two main components:
Data Cleaning - Preparation and transformation of raw laptop data
Exploratory Data Analysis (EDA) - Statistical analysis and visualization of cleaned data

Data Cleaning Process:-
The data cleaning process involved standardizing data types, removing unnecessary columns, extracting component information, and organizing storage information. Memory usage was reduced from approximately 263 KB to 196 KB through these procedures.

Exploratory Data Analysis Process:-
The exploratory data analysis (EDA) involved both univariate and bivariate analysis to understand laptop specifications and pricing trends. Univariate analysis examined basic statistics for numerical and categorical columns, such as price, storage, and processor type. Bivariate analysis explored relationships between different laptop features, including correlations between price and specifications like RAM, weight, screen size, and GPU type, providing insights into factors influencing laptop pricing.

Visualization - The results of the bivariate analysis conducted in SQL were visualized using Excel charts, including 100% clustered column charts, line charts, and scatter plots, to effectively illustrate relationships between laptop specifications and pricing trends.

Note: Detailed SQL queries, Excel analysis files and process documents outlining the data cleaning and exploratory data analysis (EDA) steps are available in this repository.
